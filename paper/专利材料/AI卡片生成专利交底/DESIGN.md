# DESIGN.md — AI卡片生成专利交底

## 设计定位

清爽简约的工程交底风格：白底、黑灰文字、暗红只作焦点。全篇无照片级配图——专利交底的"图"是**示意图**（SVG 线稿风），与摄影/插画区隔。用户显式指令优先：白背景、黑/灰/暗红三色、暗红仅用于重点文字与装饰。

## 1. 画布与母版（A/B/C 三区，全篇严格一致）

| 区 | 垂直位置 | 高度 | 规则 |
|---|---|---|---|
| A · 标题块 | 0–110px | 110px（上 padding 28） | 左侧：主标题 30px bold 墨黑 + 暗红短粗杠（28×6）骑在标题上方；右侧：单元编号 "01/06" 14px 灰 |
| B · 内容区 | 110–655px | 545px | 一切正文/图/表；左右 padding 64 |
| C · 页脚条 | 655–720px | 65px（下 padding 22） | 左：`AI卡片生成专利交底 · 内部资料`；右：页码 `NN / 07`，14px 灰 |

页面 padding：上下见三区，左右 64px。Hero 页（P2/P5）标题块同规格，不特殊化。

## 2. 颜色系统（4 hex，全篇封闭；2026-10-30 用户纪律修订）

| 角色 | hex | 用途 | 面积 |
|---|---|---|---|
| 底色 | `#FFFFFF` | 页面背景 | 主导（≥60%） |
| 墨黑 | `#1A1A1A` | **仅用于文字**（标题、正文、表头文字）。**禁止**作任何填充、描边、SVG 线稿 | 文本层 |
| 灰阶 | `#595959`（次级文字 / SVG 描边）/ `#8C8C8C`（脚注）/ `#E6E6E6`（发丝线、**表头填充**）/ `#F7F7F7`（浅面板底、表格高亮列填充） | 辅助 | ≤30% |
| **暗红（强调）** | `#8B1E24` | 巨型数字、关键词、序号、装饰杠、链接、表头"本发明"列、红底白字徽章（独权级 / 针对标签 / M1 节点） | **≤10%（Hero 页 ≤15%）** |

- **配色纪律（用户 2026-10-30 明示）**：只用黑 / 灰 / 红三色 + 白背景；黑色只出现在文字上；文字容器填充只用灰色；**浅红色调（#FDF6F6、rgba 红 6%/5%）一律不用**；红底白字的强调元素（徽章、红表头、M1 盒）保留。
- 渐变：**不用**。阴影：仅 `0 2px 12px rgba(26,26,26,0.06)` 用于浮起卡片。

## 3. 字体系统

| 层级 | 字号/字重 | 字体 |
|---|---|---|
| 巨型数字/锚点 | 56–64px bold | `'Helvetica Neue', Arial`（数字） |
| 页面主标题 | 30px bold | `'Source Han Sans SC','Microsoft YaHei',sans-serif` |
| 卡片小标题 | 17–18px bold | 同上 |
| 正文 | 14–15px regular，行高 1.55 | 同上 |
| 表格 | 13–14px | 同上 |
| 脚注/页码 | 12–13px | 同上 |

- 巨型数字必须 bold + 暗红；与正文灰黑形成"暗红焦点—黑灰基座"关系。

## 4. 信息密度门禁

常规内容页留白 ≤ 30%（P5 巨型数字页允许 35%）；每页正文 ≥ 200 字；每页 ≥ 1 个视觉锚点（≥48px 数字或 ≥40% B 区示意图）；容器填充率 ≥ 85%，卡片尾元素 `marginTop:'auto'` 钉底。

## 5. 配图系统（全 SVG 示意图，风格统一）

| 级 | 内容 | 规格 |
|---|---|---|
| L1 | P1 业务场景示意（手机线稿+卡片+指令气泡）；P2 流水线架构图（全宽） | B 区 ≥ 40% |
| L2 | P3/P7 对比表与检索表（Table 组件承担） | 表格为主体 |
| L3 | 暗红装饰杠（A 区，28×6，全篇同位）；页脚项目名 | 位置全篇一致 |

SVG 统一线稿风：1.5px 描边、墨黑主色、灰辅助、暗红仅标"本方案/关键路径"。**无 ImageGen 生图**——本 deck 的视觉语言是工程示意图（结构化元素，SVG 是规范允许且更合适的载体）。

## 7. 自检返工触发

任一页：出现 4 hex 之外的颜色 / 暗红面积超限 / 相邻页版式重复 / 表格行高拥挤（<34px）/ 巨型数字 <48px → 返工该页。
